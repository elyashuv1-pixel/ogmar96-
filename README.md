# מערכת ביקורות הרבנות – אוגמ״ר 96

אפליקציית ווב (PWA) לטלפון, נפרדת לגמרי ממערכת רבנות פקמ״ז, ובנויה על הבסיס שלה.

## שש הביקורות
1. **מקררים** – מקרר ירקות, מקרר חלבי, מקפיא בשרי
2. **מטבחונים** – רפואה, אג״ם, לשכת מאו״ג, מודיעין, תקשוב, סמבציות
3. **חדרי שטיפה** – בוקר, צהריים, ערב
4. **בית כנסת** – לפי השאלון הקיים
5. **חדר מכ״ש** – ניקיון יומי, שטיפה פעמיים בשבוע, עדכון טבלת פגי תוקף
6. **טרקלינים** – לפי השאלון הקיים

השאלות מוגדרות בראש הסקריפט ב-`index.html` (המשתנה `CATS`) – אפשר לערוך שם שאלות, פרקים וסוג תשובה
(`ok` תקין/לא תקין · `ex` קיים/לא קיים · `mix` אין/יש ערבוב · `done` בוצע/לא בוצע · `has` יש/אין).

בכל סעיף: תשובה, לא נבדק / לא רלוונטי, "דווח בעבר?", הערות, צילום במצלמה, בחירה מהגלריה. ליקויים נפתחים אוטומטית למעקב בסיום הביקורת.
דוח PDF כולל את כל התמונות מתחת לסעיף שאליו צורפו.

## מסד נתונים והרשאות
האפליקציה מחוברת לפרויקט Supabase נפרד של אוגמ״ר 96 (`config.js`). הכניסה מחייבת דוא״ל וסיסמה.
הרשמה → אימות דוא״ל → אישור מנהל ← תפקידים (רב האוגדה, נגד רבנות אוגדתי, משגיח כשרות, מנהל המערכת).
ההרשאות מוגדרות ב-`supabase/schema.sql` (RLS).
